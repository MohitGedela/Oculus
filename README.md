
# RetinaSense 🔬 
### Initial Research & Preparation

RetinaSense explores how computer vision can support the early screening of diabetic retinopathy (DR) using retinal fundus images.

Before beginning model development, our team is researching the datasets, preprocessing methods, and image quality criteria needed to build a reliable ML pipeline.

---

## 🎯 Current Objectives

- Understand the available retinal image datasets and their label distributions.
- Investigate how to standardize images before model training.
- Identify image quality issues that could affect model reliability.
- Explore tools and libraries for building the data processing pipeline.
- Establish a collaborative GitHub workflow for the project.

## 🔍 Key Questions for Our First Mentor Meeting

1. **Preprocessing:** What preprocessing steps should we standardize across datasets without losing relevant retinal features?
2. **Image quality:** Which quality indicators and assessment methods should we investigate first?
3. **Datasets:** Which datasets are best suited for initial development and external evaluation?
4. **Class imbalance:** What strategies should we consider if certain DR severity grades are underrepresented?
5. **Pipeline:** Which tools and libraries would be appropriate for our initial workflow?
